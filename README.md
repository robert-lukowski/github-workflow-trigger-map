# github-workflow-trigger-map

`github-workflow-trigger-map` is a future tool for visualizing GitHub Actions
workflow trigger relationships in repositories that contain multiple pipelines.

No application logic has been implemented yet. The
[`examples/sample-repo`](examples/sample-repo) directory contains harmless,
synthetic workflows for development and testing.

The sample workflows are nested below the example repository so they do not run
as GitHub Actions for this repository.
